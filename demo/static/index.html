Try this

  1. Open Tab A and let it stream.
  2. Open Tab B while A is running. It gets 429 from the per-session lease.
  3. Disconnect A or let it finish.
  4. Open B again. The slot is free.

What you are seeing

  • Each stream is a synthetic 20-second SSE response. No LLM calls or API keys are involved.
  • The lease lives in Redis with a 25-second TTL and is renewed while the response is open.
  • Limits: 1 per session, 2 per network, 20 globally.
  • Request rate limit: 30 stream attempts per minute per IP.
  • Tab B is rejected by the per-session lease. A third session from the same network would hit the per-IP guard.
  • If Redis is unavailable, the API returns 503 instead of silently allowing streams.
